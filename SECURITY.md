# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The AgriDecision AI core team takes security vulnerabilities seriously.

If you discover a security flaw or vulnerability within AgriDecision AI:

1. **Do NOT open a public GitHub issue.**
2. Send an email describing the vulnerability to `security@agridecision.ai`.
3. Include details regarding reproduction steps, affected endpoints, or potential impact.

The security team will acknowledge receipt of your report within **24 hours** and provide periodic updates regarding remediation.
